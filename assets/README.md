## UI boundary

The implemented shell remains governed by the Focus / Navigate / Inspect HIO baseline. Product-direction artwork can show capability families such as Research, Create, Solve, Local, Assist, Spaces, Altru Companion and the Capability Compiler without requiring those controls to become permanent browser chrome.

## Platform language

Windows, macOS, Linux, Android and iOS are the target operating-system family. Verification status belongs in `../docs/PLATFORM-MATRIX.md`.

PWA is not an operating system. If represented, it must be labeled **portable version**.
