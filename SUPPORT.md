# Support

Altru Browser is experimental.

## Questions and development help

Use GitHub issues for reproducible bugs, feature discussions and development questions that are appropriate to discuss publicly.

Before opening an issue:

- search existing issues;
- include the exact commit or version;
- include platform details;
- provide minimal reproduction steps;
- separate observed behavior from expected behavior.

## Security

Do not file exploitable vulnerabilities as public issues. Follow `SECURITY.md`.

## Production support

There is currently no production-support SLA. The project should not yet be used as the sole browser for high-value or security-critical workflows.
