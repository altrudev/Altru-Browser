# Privacy Principles

Altru Browser is designed around data minimization.

## Principles

- no unnecessary telemetry;
- no behavioral tracking required for normal browser operation;
- permissions should be explicit and purpose-bound;
- local processing is preferred when practical;
- data collection must be documented before it is introduced;
- diagnostics should be separable from browsing history and personal content;
- private browsing must not be marketed beyond what is technically enforced.

## Current state

The experimental native engine does not provide a complete consumer privacy model yet. This document defines the direction that future browser-shell and networking work must preserve.

Any proposal that adds telemetry or remote data collection requires explicit documentation, threat analysis and community review.
