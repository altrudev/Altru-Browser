# Changelog

All notable community releases of Altru Browser will be recorded here.

The project follows evidence-gated experimental releases rather than claiming production maturity from version numbers alone.

## Unreleased

### Added

- public Altru Browser community repository;
- Code for Humanity project identity;
- native DOM/HTML foundation;
- bounded CSS/cascade/invalidation;
- native layout and retained-scene foundation;
- explicit resource authority boundary;
- cross-platform PlatformHost contract;
- deterministic execution evidence;
- community contribution, security, governance and release documentation;
- clean-room community-release audit.

### Experimental

- optional Taffy geometry candidate;
- optional Servo 0.6.0 compatibility/reference path.

### Not yet promoted

- full web compatibility;
- JavaScript/Web API runtime;
- production GPU renderer;
- full flex/grid conformance;
- production security maturity;
- generalized browser performance claims.
